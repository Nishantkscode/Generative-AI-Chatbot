# 🤖 Generative AI Chatbot

Your personal AI-powered chatbot built with modern web technologies and Google's Gemini API!

Artificial Intelligence is changing the way we interact with technology. I built this project to explore Generative AI and create a simple, interactive chatbot that allows users to communicate with an AI assistant through a web interface.

The project combines HTML, CSS, and JavaScript to provide a clean and user-friendly experience.

## ✨ Features

- **AI-Powered Conversations:** Interact with an AI assistant using Google's Gemini API.
- **Interactive Chat Interface:** Send messages and receive AI-generated responses.
- **User-Friendly Design:** Simple and clean web interface.
- **Real-Time Interaction:** Communicate with the chatbot directly through the browser.
- **Modern Web Technologies:** Built using HTML, CSS, and JavaScript.

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Gemini API

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/Nishantkscode/Generative-AI-Chatbot.git
```

### 2. Move into the project directory

```bash
cd Generative-AI-Chatbot
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure the Gemini API

If the project requires a Gemini API key, configure it using a secure backend or environment variable. Never publish your private API key in frontend JavaScript or GitHub.

### 5. Run the application

Open `index.html` in your browser or use the VS Code Live Server extension.
